C# WinForms MySQL BCrypt Visual Studio 2022 WAMP ADO.NET BTS SIO SLAM Épreuve E6

Réalisation n°2 de l'épreuve E6 BTS SIO SLAM — session 2025. Application WinForms C# d'administration de base de données, conçue comme interface back-office du projet léger (site e-commerce PHP). Authentification sécurisée par BCrypt, navigation entre les tables MySQL, et opérations CRUD complètes via une interface dynamique générée à la volée. Réalisé seul, de décembre 2024 à avril 2025, à H3 Hitema Paris 15e.

Code · Form1

Connexion sécurisée avec BCrypt

La connexion récupère le hash stocké en base pour l'email saisi, puis le compare au mot de passe via BCrypt.Net.BCrypt.Verify(). La requête SQL est paramétrée pour éviter les injections.

// Form1.cs — vérification de l'identité
string query = "SELECT password FROM users WHERE email = @Email";
MySqlCommand cmd = new MySqlCommand(query, conn);
cmd.Parameters.AddWithValue("@Email", email);
MySqlDataReader reader = cmd.ExecuteReader();

if (reader.HasRows && reader.Read())
{
    string storedPassword = reader.GetString(0);

    if (BCrypt.Net.BCrypt.Verify(password, storedPassword))
    {
        Form2 form2 = new Form2();
        form2.Show();
        this.Hide();
    }
}

Chargement dynamique des tables MySQL

Au démarrage de Form2, la liste de toutes les tables de la base est récupérée et affichée dans le CheckedListBox. La sélection d'une table déclenche immédiatement un SELECT * affiché dans le DataGridView.

// Form2.cs — récupération des tables
private void LoadDatabaseTables()
{
    MySqlCommand cmd = new MySqlCommand("SHOW TABLES", conn);
    MySqlDataReader reader = cmd.ExecuteReader();

    while (reader.Read())
        NomDesTables.Items.Add(reader[0].ToString());
}

// Affichage du contenu de la table sélectionnée
private void DisplayTableData()
{

}
Code · Form3

Interface CRUD générée à la volée

Form3 utilise DESCRIBE [table] pour récupérer la structure de n'importe quelle table, puis génère automatiquement un Label et un TextBox par colonne. Le champ password est détecté et masqué. La modification hache le nouveau mot de passe en BCrypt avant l'UPDATE.

// Form3.cs — génération dynamique des champs
string query = $"DESCRIBE {tableName}";
MySqlDataAdapter dataAdapter = new MySqlDataAdapter(query, conn);
DataTable dt = new DataTable();
dataAdapter.Fill(dt);

foreach (DataRow row in dt.Rows)
{
    string columnName = row["Field"].ToString();
    Label label = new Label { Text = columnName };
    TextBox textBox = new TextBox { Width = 200 };

    if (columnName.ToLower() == "password")
        textBox.PasswordChar = '*';   // masqué
    else
        textBox.Text = rowData[columnName];

    textBoxes[columnName] = textBox;
    flowLayoutPanel1.Controls.Add(label);
    flowLayoutPanel1.Controls.Add(textBox);
}
// Modification — hash BCrypt si champ password
foreach (var entry in textBoxes)
{
    if (entry.Key.ToLower() == "password")
    {
        string hashed = BCrypt.Net.BCrypt.HashPassword(entry.Value.Text, workFactor: 10);
        updateFields.Add($"{entry.Key} = '{hashed}'");
    }
    else
        updateFields.Add($"{entry.Key} = '{entry.Value.Text}'");
}
string updateQuery = $"UPDATE {tableName} SET {string.Join(", ", updateFields)} WHERE id = {recordID}";

Extraits de code

connexion.php — authentification via PDO avec password_verify(). La requête est paramétrée pour prévenir les injections SQL. 

// connexion.php — vérification email + hash
$stmt = $conn->prepare("SELECT * FROM users WHERE email = :email");
$stmt->bindParam(':email', $email);
$stmt->execute();

if ($stmt->rowCount() > 0) {
    $user = $stmt->fetch(PDO::FETCH_ASSOC);

    if (password_verify($password, $user['password'])) {
        $_SESSION['username'] = $user['username'];
        header("Location: accueil.php");
        exit();
    }
}

inscription.php — vérification de l'unicité de l'email, hachage du mot de passe avec password_hash() avant insertion. 

// inscription.php — vérification email + hash avant INSERT
$stmt = $conn->prepare("SELECT * FROM users WHERE email = :email");
$stmt->bindParam(':email', $email);
$stmt->execute();

if ($stmt->rowCount() == 0) {
    $hashedPassword = password_hash($password, PASSWORD_DEFAULT);
    $stmt = $conn->prepare(
        "INSERT INTO users (username, email, password) VALUES (:username, :email, :password)"
    );
    $stmt->bindParam(':username', $username);
    $stmt->bindParam(':email', $email);
    $stmt->bindParam(':password', $hashedPassword);
    $stmt->execute();
}

index.php — filtres dynamiques par type de manga et par tranche de prix. La requête SQL est construite conditionnellement selon les paramètres GET. 

// index.php — construction dynamique de la requête avec filtres
$sql = "SELECT id, name, image, price FROM products WHERE 1=1";
$params = [];

$filterConditions = [];
if (isset($_GET['filter_shonen'])) $filterConditions[] = "type = 'shonen'";
if (isset($_GET['filter_shojo']))  $filterConditions[] = "type = 'shojo'";
if (isset($_GET['filter_seinen'])) $filterConditions[] = "type = 'seinen'";
if (isset($_GET['filter_isekai'])) $filterConditions[] = "type = 'isekai'";

if (!empty($filterConditions))
    $sql .= " AND (" . implode(" OR ", $filterConditions) . ")";

if (isset($_GET['price_min'], $_GET['price_max'])) {
    $sql .= " AND price BETWEEN :min_price AND :max_price";
    $params[':min_price'] = (float) $_GET['price_min'];
    $params[':max_price'] = (float) $_GET['price_max'];
}

$stmt = $pdo->prepare($sql);
$stmt->execute($params);

cart.php — gestion du panier en session PHP. Ajout, suppression unitaire et vidage complet. Le total est calculé à la volée. 

// cart.php — ajout, suppression, total
if (isset($_POST['remove_item'])) {
    $key = array_search($_POST['item_id'], $_SESSION['cart']);
    if ($key !== false) {
        unset($_SESSION['cart'][$key]);
        $_SESSION['cart'] = array_values($_SESSION['cart']);
    }
}

// Calcul du total avec gestion des quantités
$quantities = array_count_values($cart_items);
$total = 0;
foreach ($quantities as $item_id => $quantity) {
    $product = array_values(array_filter(
        $products, fn($p) => $p['id'] == $item_id
    ))[0];
    $total += $product['price'] * $quantity;
}

admin_dashboard.php — interface d'administration entièrement dynamique. SHOW TABLES récupère toutes les tables, puis chacune est affichée avec ses données et des liens Edit/Delete/Add. Les mots de passe sont masqués côté affichage. 

// admin_dashboard.php — affichage dynamique de toutes les tables
$stmt = $conn->query("SHOW TABLES");
$tables = $stmt->fetchAll(PDO::FETCH_ASSOC);

foreach ($tables as $table) {
    $tableName = $table['Tables_in_' . $dbname];
    $stmt = $conn->prepare("SELECT * FROM $tableName");
    $stmt->execute();
    $rows = $stmt->fetchAll(PDO::FETCH_ASSOC);

    foreach ($rows as $row) {
        foreach ($row as $column => $data) {
            // Masquer les mots de passe
            if ($column === 'password') { echo "<td>*****</td>"; }
            else { echo "<td>" . htmlspecialchars($data ?? '') . "</td>"; }
        }
        // Liens Edit / Delete par ID
        echo "<a href='edit.php?table=$tableName&id={$row[$idColumn]}'>Edit</a>";
        echo "<a href='delete.php?table=$tableName&id={$row[$idColumn]}'>Delete</a>";
    }
    echo "<a href='create.php?table=$tableName'>Add</a>";
}

navbar.php — navigation conditionnelle selon l'état de session. Invité et utilisateur connecté ne voient pas les mêmes liens.

<?php endif; ?>
